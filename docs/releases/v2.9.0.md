# 牙牙消息 v2.9.0 发布说明

发布日期：2026-11-21

> 以下汇总 **v2.8.0 → v2.9.0** 的全部新增、修复与体验优化（含 v2.8.1 修复、全量 UI / 材质统一与 QChat/播放器重构）。

## 新增

- 全站轻量 G2 连续曲率圆角引擎：Android 原生新增 `ContinuousCornerView`（纯路径缓存 + 同路径 1px 描边，无整屏抓图/Shader 开销），iOS 同步启用 `borderCurve: 'continuous'`
- 全站玻璃与二级页统一升级：18 个二级页顶栏统一为悬浮双岛液态玻璃样式，右上角操作按钮升级为极简圆形图标
- 音乐界面全面重做：顶部双岛玻璃栏（纯图标搜索 / 专辑切换 / 随机 / 全部播放 / 刷新）、悬浮玻璃 MiniPlayerBar（底部 2.5px 细进度条 + 上滑直达全屏）、全屏播放器氛围封面底衬、分层对称主控按钮与固定行高队列弹层
- 新增自定义液态玻璃胶囊开关（`GlassToggle`），替换使用偏好与弹幕设置中的系统原生开关
- 使用偏好新增「房间列表显示消息时间」独立开关，支持灵活控制大小房间最近消息时间展示
- 账号设置页「口袋48Token登录」新增「清空」快捷按钮，可一键清空 Token 输入框；首页「私信」入口支持未读红点角标与自动刷新
- 直播间与成员主页交互升级：支持点击直播左上角主播名/头像打开资料卡并一键关注/跳转「成员档案」，`成员档案` 页面右上角同步新增关注开关；房间列表顶部新增「全部成员」快速关注入口，房间卡片恢复快捷关注心形按钮
- 新增成员横屏直播自动探测与兼容模式：原生像素抽检区分真横屏直播与黑边假横屏竖屏，真横屏直播自动切换兼容横屏全屏与 16:9 小窗，口袋直播控制栏与更多菜单新增一键横屏/竖屏切换按钮
- 新增直播结束总结展示页；进入房间或小房间确认开播但官方直播列表未展示时支持兜底显示（`useDiscoveredLivesStore`），小房间列表缺失时支持进房及后台批量补拉同步显示
- 翻牌页面新增可搜索成员选择器（`MemberPicker`）与视角筛选弹层，统一「成员档案」四按钮自适应换行与间距排版

## 修复

- 修复 QChat 实时推送及 VPN / Fake-IP 环境下的断连与切换卡顿：改为 `App.tsx` 全局持久 QChat 会话，按会话去重频道订阅并移除冗余轮询，进退房、切换与列表实时推送顺滑无阻
- 修复非成员（粉丝）消息、连麦系统通知误改写成员列表最后发言时间与预览文案的问题，房间时间缓存升级至 `v2` 并校验文案一致后才复用；同步移除公演/生日会日程预告与成员直播状态的误合并
- 修复大房间头像/背景元数据被错误缓存为小房间后无法恢复的问题，加入自动元数据校验自愈
- 修复音乐暂停后继续播放或切后台触发原生 `YayaExoService` / `RadioExo` 崩溃的问题，以及切歌/切页后黑胶专辑封面停止转动、续播进度偶发归零问题
- 修复直播间连麦/PK 切换缓冲卡顿与自动重试、横屏控制栏与弹幕输入框体验、弹幕列表智能吸底滚动及顶部叠加遮挡间距问题
- 修复系统小窗（PiP）切回/跳转偶发黑屏、双击缩放画面裁切比例错误及参数被第三方播放器覆写的问题
- 修复房间列表点击整个卡片左侧误进小房间的问题：收窄「小房间」触发热区至 `[小]` 标签及小房间消息文本，其余区域默认进大房间
- 修复 `AppToast` 首帧闪烁/弹跳与 `FilterChips` 渐隐掉帧，以及房间/翻牌/使用偏好等页面键盘高度（`KeyboardEvents`）与排版边距适配问题
- 修复公开直播接口携带过期 Token 解析异常及 401005 鉴权报错；修复 `source2 / source3` 图床 403 时图片不显示并自动回退 `source1`
- 修复首页直播 banner 切换闪烁问题，升级为并排预加载横向分页轮播并支持左右跟手滑动切换；打通首页私信红点与「私信列表」未读状态同步
- 修复二级页面及音乐库左上角返回玻璃胶囊仅小图标可点的问题，改为整颗胶囊均可点击返回；精简音乐卡片跨端副标题截断问题

## 优化

- 全面统一全软件卡片材质与圆角规范：全站卡片统一为轻磨砂玻璃材质（`GlassSurface role="card" frostedOnly`，`22dp` 连续曲率圆角 + 1px 顶部高光描边，零逐卡实时模糊开销），覆盖首页快捷入口/工具/公演/最近播放及房间、上麦、翻牌、下载、B站、公演、排行、发票、私信、电台等全部页面，显著提升滑动流畅度
- 优化前后台与切页功耗：首页歌词仅在播放时低频刷新，跑马灯改原生动画，直播呼吸点、B 站状态轮询及私信未读轮询在失焦/后台时自动暂停并做节流保护
- 优化音乐列表与全屏播放流畅度：去重收藏集合实现 O(1) 查找、`React.memo` 网格卡、按需构建队列并拆分进度条/歌词刷新域
- 优化登录身份体验：移除塞纳河48入口，统一使用口袋48登录与凭证管理
