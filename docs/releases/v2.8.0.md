# 牙牙消息 v2.8.0 发布说明

发布日期：2026-11-18

## 新增

- 重写设置页面：账号卡置顶、外观与显示合并、成员数据压缩、语言弹层、关于入口下移
- 新增首页模块仪表盘：模块显示/隐藏、排序
- 新增房间宽屏双栏布局：聊天与播放器分栏显示
- 新增直播结束总结页：标题、成员、开始时间、时长、贡献榜前三
- 新增房间公告栏与公告按钮，可展开/收起
- 新增应用内反馈、赞赏码与独立关于软件页
- 新增房间名、房间背景缓存，进房首帧即有内容
- 新增多语言补全、图标按钮无障碍标签
- 新增图片查看器下载/分享按钮的安全区布局

## 修复

- 修复系统小窗切回全屏黑屏
- 修复小窗双击缩放时画面左右裁切、比例错误
- 修复小窗竖屏直播比例变横屏
- 修复 PK / 连麦开始不自动刷新、切流花屏
- 修复直播列表参数错误时误清空已有列表
- 修复录播分享页 `.html` 地址无法播放
- 修复房间直播公告直链进入时不显示
- 修复成员档案数据不更新、档案字段缺失
- 修复签名器卸载后不重挂载、每 10 秒超时
- 修复成员库旧数据覆盖导致房间映射丢失、大小房间进不去
- 修复下载完成被误判失败、下载任务恢复异常
- 修复媒体通知进度时间戳、歌词制作名单显示
- 修复账号设置页输入框被键盘遮挡
- 修复首页工具入口文字截断、底栏遮挡
- 修复翻牌语音/视频相对路径地址拼接错误
- 修复 Tab 切页空白/半屏错位
- 修复首页 banner 关注/置顶排序与骨架高度
- 修复图片下载一次存两张、图片查看器按钮压住图片

## 优化

- 优化启动：成员库解析移到开屏期间，避免首屏后重复解析
- 优化切页：原生 pager + 页面预挂载，切换不再空白
- 优化长会话：消息对象复用、页面冻结、房间消息渲染开销
- 优化图片加载：NetworkImage 缩略图、失败占位、封面遮罩
- 优化签名：PA 缓存复用，降低重复 WebView 签名等待
- 优化房间进出动效、底部输入条与 Dock 对齐
- 优化小窗比例、PiP 控件和播放器 UI 残留
- 优化首页/设置/房间的圆角、玻璃材质、标题规格与间距
- 优化房间公告、发言条和 Dock 的位置与可读性
- 默认构建 `arm64-v8a` / `x86_64`，不再默认构建 `armeabi-v7a`
