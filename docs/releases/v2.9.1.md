# 牙牙消息 v2.9.1 发布说明

发布日期：2026-11-22

> 本版本聚焦 **v2.9.0 → v2.9.1** 的私信/翻牌交互重构、启动图标与房间细节打磨，以及每日更新检查弹窗。

## 新增

- 每日首次打开检查更新弹窗：当检测到有更高版本且当前尚未升级时，每天首次冷启或跨天回到前台自动弹出一次更新安装弹窗（支持显示 Release 更新说明），当天关闭后不再重复弹窗，保留「设置 → 关于」新版本提示红点

## 优化与修复

- 私信页面重构与语义修正：成员会话统一采用玻璃态私密翻牌输入卡片（自动预选首个开放档位、支持余额跳转），互关粉丝会话保持直接文字与图片私信输入栏；列表补回最新消息时间展示、统一真实接口头像（取消首字母兜底圆圈）、将置顶/排序收拢为长按操作菜单，并修复系统深色模式下聊天区误显黑底的问题
- 翻牌统计页面重整：去除顶部冗余计数横幅，合并总览统计与分型比例条；「成员排名」支持默认折叠展示 Top 3 并可展开全部，「翻牌明细」将成员筛选收拢到标题行弹层，完整保留 `回复于` 时间、耗时、鸡腿数与 8 天倒计时信息
- 房间与开屏体验打磨：平滑房间进出过渡动画、紧凑「已关注」标签尺寸与输入栏底距，并统一深浅色开屏衔接与 G2 连续曲率应用图标效果
