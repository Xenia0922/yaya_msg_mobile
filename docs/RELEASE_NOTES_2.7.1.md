# 牙牙消息 2.7.1

## 稳定性与发布

- 统一应用版本为 `2.7.1`，Android `versionCode` 升至 `2070006`。
- 修复版本校验脚本因三段版本解析错误导致的发布门禁失败。
- Release 构建支持通过 `RELEASE_*` Gradle 参数使用正式签名；未配置时保留本地 debug 兜底并明确输出警告。
- 关闭 Android 自动备份，降低本地设置和登录凭证进入系统备份的风险。

## 网络与启动

- 修复公演参与成员请求的 `application/x-www-form-urlencoded` body 被错误 JSON 序列化的问题。
- `WebViewSigner` 在 JS 开屏期间保持挂载，提前预热签名模块。
- 设置持久化增加串行写入和内存缓存，避免快速连续修改时互相覆盖。

## 主题与页面状态

- 修复“跟随系统”主题下组件 Palette 仍固定为浅色的问题。
- 修复消息、私信快速切换成员时旧请求覆盖新内容的竞态。

## 质量门禁

- 新增网络请求体编码专项测试。
- 新增 GitHub Actions：TypeScript、版本校验、核心测试和 Diff 检查。
