# 2.8.1 真机 UI / 性能审计

设备：OnePlus PJZ110，Android 17，1440×3168 / 640dpi

## 实测页面

- 首页
- 直播（直播 / 录播）
- 房间列表与房间详情
- 设置
- 使用偏好
- 关于软件
- 音乐库
- 账号设置 / 私信列表
- 深色主题下的首页与设置

## 性能基线

冷启动：127ms，37 帧，Janky 8.11%，99th 89ms  
Tab 切换：直播 2.86% / 房间 0% / 设置 7.35% / 首页 0%

## MuMu 实测范围

首页、直播 / 回放、房间列表与详情、设置、账号设置、私信列表、音乐库、翻牌、上麦、下载管理、公演记录、B站直播、鸡腿榜、使用偏好、关于软件均已打开验证；页面切换与滚动无应用崩溃。

## 本轮优化后实测

Tab 切换：直播 0% / 房间 0% / 设置 5.88% / 首页 0%  
冷启动：140ms（冷启动受系统后台任务影响，单次统计有波动）  
130% 系统字体：首页结构与快捷入口未溢出，工具行仍按横向滚动处理。

## 布局与易用性结论

- 首页：快捷入口 4 格完整；工具 chips 为横向滚动，右侧露出下一项作为可继续滑动的提示。
- 直播：筛选 chips 与搜索按钮并排，chips 过长时可横向滚动；搜索入口有明确图标。
- 房间：列表卡片信息层级清晰；房间详情输入条、公告和媒体消息均在安全区内。
- 设置：分组清楚，底部 ListBottomSpacer 能让最后一项滚动到 Dock 上方；长账号名会截断，这是预期展示限制。
- 使用偏好：首页模块开关/排序可用，文案与状态值一致。
- 关于：版本、更新、赞赏、反馈、开源信息分区明确。
- 音乐库：双列封面与筛选 chips 布局正常；顶部团体按钮统一为 60dp 等宽 / 36dp 高 / 12px，选中态为品牌粉底白字，5 个分团按钮可同时显示。
- 深色主题：首页、设置文字和图标对比度正常，无不可读区域。

## 本轮修改

- 首页歌词 ticker：仅在播放且有歌词时运行，500ms → 1s。
- 首页公演状态轮询：60s → 120s，回前台补刷。
- B 站直播状态点动画：失焦/后台停止；开播状态轮询增加焦点门卫。
- 跑马灯文字：JS 驱动改为原生驱动。
- 音乐库均衡器：页面失焦或暂停时停止。
- 首页快捷入口/工具 chips 增加无障碍标签。
- 水平筛选条渐隐方向修正为横向，避免竖向渐变造成右侧色块。
- 工具行移除异常渐隐色块，保留原生横向滚动。
- 分段选择器统一选中态为浅粉底 + 主文字色 + tint 描边，避免灰胶囊和低对比。
- 音乐库顶部团体选择统一为 60dp 等宽，修正选中色（品牌粉底 + 白字）。
- 上麦扫描页去掉重复的「正在扫描」文案和多余 spinner，只保留顶部进度条。
- 下载管理顶部操作从「清理完成」改为「清理」，避免和状态文案混淆。
- 使用偏好开关统一为「关 / 开」单字标签。
- 直播筛选条与搜索按钮增加间距，避免贴边重叠。
- 直播页遇到服务端返回的 token/登录失效错误时，不再直接展示原始「token解析失败」，改为登录状态失效引导，可直接去重新登录。

## 后续建议

- 设置页首次进入的 7% jank 主要来自大量玻璃卡片的首次布局，可后续按区块做延迟挂载。
- 直播/房间长列表滚动建议继续用真机 `gfxinfo` 做帧率基线。
- 深色模式下若用户使用大字体，建议再做一次 font-scale 回归。
