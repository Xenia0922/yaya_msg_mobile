# 牙牙消息 2.7.1 · 全量 UI 审计与修复记录

## 审计范围

覆盖 `src/screens` 全部 26 个页面，以及导航、页头、按钮、Pill、状态态、动画、播放器外壳、MemberPicker、TabBar 和弹层组件。

## 本轮已处理

| 范围 | 处理内容 |
| --- | --- |
| 全局文字布局 | Button、Pill、SectionHeader、ScreenHeader、ListItem 增加收缩、截断和最小宽度约束，降低多语言和窄屏下的横向溢出 |
| 全局动画 | 页面切换、FadeIn、TabBar、Toast、按压动画增加停止和清理，降低快速切页残影与动画堆积 |
| 主页/Tab | 保留内容优先布局，底部滚动留白与浮动 Dock 继续避让 |
| 直播/回放 | 横竖屏尺寸改为响应式窗口尺寸，移除播放器外层与 Video 的双重旋转风险 |
| B站直播 | 横竖屏播放器同样移除双重旋转风险，保留线路、弹幕、缓冲和控制条功能 |
| 弹幕/音乐播放器 | 弹幕泳道、全屏播放器关闭手势跟随窗口尺寸变化 |
| 社区 | FAB 改为安全区相对定位，避免高密度屏抬高覆盖正文；发帖弹层增加键盘避让与可滚动表单 |
| 公演记录 | 未选成员时不再显示重复/误导状态文案 |
| 设置 | 右侧仓库、说明和状态文字不再挤压标题 |
| 发票 | 金额、状态和操作按钮设置不可压缩边界，窄屏布局更稳定 |
| 成员选择 | 已选成员文案限制为单行，避免长名称撑高页面 |
